## Featured work

### 🧰 [IntelliProcess](https://github.com/jayesh-07/pythonpackage-intelliprocess-DS-5010)
*Open-source Python package for ML data pre-processing and visualization, co-developed with a team at Northeastern (DS 5010).*

- **IntelliProcess** handles missing-value imputation, skew analysis (Box-Cox and log transforms), IQR outlier removal, and categorical encoding (one-hot, label, binary) with an automatic encoding suggestion.
- **IntelliViz** produces boxplots, correlation heatmaps, histograms, Normal Q-Q plots, and scatter plots against a chosen target.
- Fully documented with an API reference and usage examples.

`Python` `pandas` `NumPy` `Matplotlib` `Seaborn`

`Python` `R` `SQLite` `Snowflake`
